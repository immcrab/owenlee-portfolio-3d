# owenlee.xyz — 3D GitHub portfolio

A scroll-driven 3D tour through [immcrab](https://github.com/immcrab)'s GitHub
repositories, built with Next.js and React Three Fiber. As you scroll, the
camera drifts along a generated path through space, past a glowing shape for
each repo. Each one carries a short AI-written blurb, generated by Mistral
from the repo's own metadata and file contents.

## Stack

- **Next.js 16** (App Router) + TypeScript + Tailwind CSS 4
- **React Three Fiber** / **three.js** for the 3D scene, **@react-three/postprocessing**
  for bloom/vignette/chromatic aberration
- **Lenis** for smooth scrolling, **Framer Motion** for the HTML overlay animations
- **Mistral AI** for the per-repo summaries (generated offline, checked into
  `public/data/repos.json`, refreshed on a schedule — see below)

## Features

- Full 3D scroll experience: seeded wandering camera path, starfield, glowing
  per-language geometry for each repo, postprocessing bloom
- Respects `prefers-reduced-motion`: disables camera movement/effects and
  falls back to plain scroll, and a plain gradient background if WebGL isn't
  available at all
- Jump-to-repo quick nav, scroll progress bar, keyboard/screen-reader friendly
  (skip link, semantic sections, real links)
- Live-ish data: `scripts/generate-repo-data.mjs` re-ranks immcrab's repos,
  pulls representative files (README, package.json, entry points, ...) from
  each, and asks Mistral to summarize them — with a weekly GitHub Action to
  keep it fresh
- SEO basics: metadata, OG image, sitemap, robots.txt

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Regenerating the repo data

`public/data/repos.json` is checked into the repo so the site works with zero
config out of the box. To regenerate it with your own Mistral key:

```bash
cp .env.example .env.local
# fill in MISTRAL_API_KEY (and optionally GITHUB_TOKEN to raise the rate limit)
npm run generate:repos
```

This re-fetches immcrab's public repos, ranks them (real description/homepage/
stars beat placeholder test repos), pulls a handful of files from the top
`MAX_REPOS` of them, and asks Mistral for a grounded 1–2 sentence summary of
each.

A scheduled GitHub Action (`.github/workflows/refresh-repos.yml`) runs the
same script weekly against the `MISTRAL_API_KEY` repo secret and commits any
changes automatically.

## Deploying

The app builds as a fully static site (`next.config.ts` sets `output: "export"`)
so it doesn't need a Node server at runtime — no environment variables are
required; the AI summaries are pre-generated at build/commit time, not fetched
live from the browser.

### GitHub Pages (current setup)

`.github/workflows/deploy-pages.yml` builds the app and deploys `out/` to
GitHub Pages on every push to `main`. It's currently live at
**https://immcrab.github.io/owenlee-portfolio-3d/**.

`owenlee.xyz` itself is already pointed at a different repo
(`immcrab/owenlee.xyz`), so this site isn't on the custom domain yet. To move
the domain over later:

1. Disable Pages on `immcrab/owenlee.xyz` (Settings → Pages → Source → None),
   or free up the domain there — GitHub only allows one repo per verified
   custom domain per account.
2. Add a `public/CNAME` file back to this repo containing `owenlee.xyz`.
3. Repo **Settings → Pages → Custom domain** = `owenlee.xyz`, and point
   `owenlee.xyz`'s DNS at GitHub Pages: an `A` record on the apex domain to
   GitHub's Pages IPs (`185.199.108.153`, `.109.153`, `.110.153`, `.111.153`).
4. Once DNS resolves, tick "Enforce HTTPS" in the same Pages settings page.

### Vercel (alternative)

Works too — remove `output: "export"` from `next.config.ts` first (Vercel
doesn't need the static export step) and point a domain at Vercel via a
`CNAME`/`A` record instead.

## Project structure

```
src/
  app/                 routes, metadata, sitemap/robots
  components/
    canvas/            the R3F scene: camera path, starfield, repo nodes, postprocessing
    ui/                HTML overlay: hero, repo cards, outro, nav, progress bar
    providers/         Lenis-backed scroll provider
  hooks/               reduced-motion / WebGL-support / scroll hooks
  lib/                 types, camera path generator, language color map
scripts/
  generate-repo-data.mjs   GitHub + Mistral -> public/data/repos.json
```
